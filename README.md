# Auto Save Race Replay

A small addon for content creators who sometimes forget to hit **Save Full Race Replay** after the chequered flag. Finish an offline race and the addon saves the full replay automatically. You can watch it later in **Theatre** from the main menu.

## Install

1. Download the ZIP from [GitHub Releases](https://github.com/DejwR/auto-save-race-replay/releases) and import it from the **Addons** page in Swofty Launcher.
2. Enable **Auto Save Race Replay** in the profile you use and launch F1 25 through Swofty.
3. Finish an offline race. When the results screen opens, F1 25 saves the replay and shows its usual confirmation.

## Compatibility

This release supports F1 25 on Steam for Windows, game build `25251167`, with Swofty Launcher `1.8.35` or later. The addon uses the game's replay export when that option is available.
